# Game Room 2.0.2.4 — build 235

## Polski

- W deblu Axel Ponga zapowiedź serwującego i odbierającego nie wstrzymuje już meczu do zakończenia syntezy. Usuwa to przyczynę długich pauz po zmianie serwującego. Obowiązuje zwykła pauza 2,7 s, jak w singlu.

## English

- In Axel Pong Doubles, announcing the server and receiver no longer holds the match until speech finishes. This removes a cause of long pauses after a server change. The normal 2.7-second pause applies, as in Singles.
