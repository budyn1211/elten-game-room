opublikowanego ELTEN Game Room:

- autor i właściciel programu w ELTEN-ie: `papierek`;
- nazwa opublikowanej paczki: `ELTEN-Game-Room-build-176-signed.eltsetup`;

Przy tworzeniu repozytorium porównano wszystkie 130 plików aplikacji ze
źródłami buildu 176. Nie brakowało żadnego pliku i nie wykryto żadnej różnicy.

runner istniejących testów.

profilu ELTEN-a, tokenów MCP ani logów użytkownika. Eksperymentalne buildy 177,
178 i 179 nie są częścią tej bazy.
