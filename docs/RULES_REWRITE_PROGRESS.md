# Przystępne zasady wszystkich gier

18 września 2026. Polecenie użytkownika: po wcześniejszych poprawkach
przeredagować każdą grę dla początkującego, naturalnie i jasno. Źródła
zewnętrzne służą do porównania i sposobu wyjaśniania, kod rozstrzyga
zachowanie Game Roomu. PL/EN, bez zmiany silników i wariantów.

Zasady pozostają jednym dokumentem z nagłówkami dobranymi do danej gry,
nie osobnymi oknami ani schematem „cel/konfiguracja”. Wyjaśnić pojęcia,
przebieg typowej tury, rozliczenie i wyjątki w odpowiedniej kolejności.
Użyć krótkich przykładów tam, gdzie ułatwiają zrozumienie. Opisać każdą
dostępną opcję, nie kopiować nazw bez wyjaśnienia. Skróty jako lista
oparta o faktyczne definicje F1; zachować ustawienia bieżącego stołu.
